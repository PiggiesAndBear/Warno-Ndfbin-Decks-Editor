## 1. 这个工具能做什么

### 能做

| 想做的事 | 怎么做 |
|---|---|
| 某个单位从 4 个改成 6 个 | 「改件数」 |
| 把 T-72 换成 T-80 | 「换装备」 |
| 某个排里的装备种类增加 / 删掉 | 「插入条目」/「删除条目」 |
| 把**全军**（或某个师、某个营）的某装备统一换掉 | 「批量替换」 |
| 把好几**种**装备一起并成同一种 | 「批量替换」→ 勾选多行 →「统一设为…」 |
| 把好几种装备**各换各的**（A→B、C→D 一次做完） | 「批量替换」（每行给它自己的目标） |
| 给单位配不同的运输载具 | 「换装备」→「载具」 |
| 调整单位的经验等级（新兵 / 老兵 / 精英） | 「换装备」→「经验」 |

### 不能做

- **不能**新增或删除"师 / 营 / 连 / 排"这些层级结构。只能改它们**里面装的东西**。
- **不能**改单位名字、师名、营名。
- **不能**改单位数值（血量、火力、速度）或武器参数。
- **不能**跨 Mod 借用装备。原因见[第 6 章](#6-为什么找不到我的装备--我的-mod)，这条很重要。

### 适用范围

只针对 **将军模式（Army General）** 的牌组。PvP / 行动模式专用的牌组数据不会被列出来，也不会被改动 —— 这是故意的，那两类数据结构和将军模式不通用，混用会让游戏出错。

## 2. 五分钟上手

### 第 0 步：先备份（30 秒，别跳过）

把你要改的那份 `Deck.ndfbin` 复制一份留着。路径通常长这样：

```
C:\Users\你的用户名\Saved Games\EugenSystems\WARNO\mod\你的mod名\Gen\NDF\GFX\Deck.ndfbin
```

工具在覆盖原文件时会自动再存一份 `Deck.ndfbin.bak`，但你自己先复制一份更稳妥（比如复制到桌面，改名成 `Deck.ndfbin.原始`）。

### 第 1 步：启动

双击 `Warno Ndfbin Decks Editor v0.1.exe`。

第一次运行，Windows 可能弹出蓝色的"Windows 已保护你的电脑"。

这是正常的 —— 因为这个程序没有购买微软的数字签名证书。点：

```
「更多信息」 → 「仍要运行」
```

**如果什么都没发生**：可能被杀毒软件静默拦了。看[第 8 章](#8-常见问题与故障处理)。

启动大约需要 1～2 秒（第一次运行会慢一些，5 秒左右）。

### 第 2 步：选 Mod

窗口最上面第一行有个 `Mod` 下拉框。点开，选你要改的 mod。

列表里的每一项后面会标出处：

通常会显示
```
Test                               · 本机
AG Framework - XXX                 · 本机
A World in Flames                  · 创意工坊
Northern Thunder                   · 创意工坊
某个mod（无牌组）                     ← 灰色，点不了
```

- `· 本机` = 在"保存的游戏"文件夹里的 mod
- `· 创意工坊` = 从 Steam 创意工坊订阅的 mod
- `（无牌组）` = 这个 mod 没有编译好的牌组文件，改不了。**灰色的点不动是正常的**，不是坏了。

**找不到你的 mod？** 点右边的「打开 mod 文件夹」按钮，手动指定位置。见[第 6 章](#6-为什么找不到我的装备--我的-mod)。

### 第 3 步：找到你想改的地方

选完 Mod 后，界面会自动显示这个 mod 的所有师。

1. **国家 Nat**：先选国家，师列表会缩短（比如从 233 个师缩到 54 个）。不选就是全部。
2. **师 Div**：选一个师。也可以直接在框里打字筛选，比如打 `SOV_TK`。
3. **营搜索**：嫌营太多，在右边框里打营名，比如 `pion` 或 `11Sq`。
4. **左侧树**：点开 师 → 营 → 连 → 排，找到那一"排"（Pl）。

> 小技巧：师的名字后面括号里写着营数，比如 `SOV_TK_Nord  (57 营)` —— 一眼能看出哪个师最大。
> 连和排的前面会跟着**"这一排装了什么"**，比如 `连Co 0 T72M1 ×4 · BMP-2 ×2`，
> 比名字还直观（尤其当 mod 没提供连名、排名的时候）。

### 第 4 步：改

在左侧树里选中**排**（或更下面的条目）之后，**右边表格**会列出**这个营**的全部装备行
（整营都显示出来便于对照），你选中的那一排的行会**高亮**。

```
条目  连Co  排Pl  装备              运输        经验   件数  槽位     pack#
#1    Co0   Pl0   T72M1_TCH          —          继承   4     0-3      #2270
#2    Co0   Pl0   BMP_2_SOV          —          3      3     4-6      #1183
#3    Co0   Pl1   MANPAD_Igla_SOV    —          2      2     7-8      #900
```

- **一行 = 一样装备**（一"条"）。要改哪一行，先**用鼠标点那一行**（点最左边的 `#1` 那格）。
- 点完再按底部的按钮：`改件数` / `换装备` / `插入条目` / `删除条目`。
- 表格上方会显示这句话，比如：`连Co 0 排Pl 0：2 条，占槽位 [0,1,2,3] —— 改件数会重排该营全部下游窗口`。

**最快的改法**：直接**双击**表格里的一行 = 打开「换装备」。

### 第 5 步：保存

按右下角的 `保存`。

1. 工具先自检。有问题会弹窗拒绝保存（说明见[第 5 章](#5-保存先看这一节再动手)）。
2. 弹出"保存到"对话框，**路径已经默认填好**了，直接点"保存"。
3. 覆盖原文件时，旁边会多出一个 `Deck.ndfbin.bak`（原始版本）。
4. 弹出「已保存」，显示路径和文件大小。

### 第 6 步：进游戏验证

**关掉游戏重新进**，去将军模式里找到那个营，确认改动生效了。

> 只到主菜单可能不够，游戏一般在启动时读取牌组。保险做法是完全退出游戏再启动。

**如果游戏里没变化**，先别急着改第二遍 —— 看[第 8 章 FAQ 第 5 条](#8-常见问题与故障处理)。

## 3. 界面逐块认识

```
┌──────────────────────────────────────────────────────────────────────┐
│ Mod [Test ▾]  [打开 mod 文件夹]  国家 Nat [全部国家▾]  师 Div [输入以筛选]  营搜索 [      ] │  ← 第一行：筛选
├───────────────────────────────┬──────────────────────────────────────┤
│ 组织                           │ 装备条目（一行 = 一个窗口，整行同时换装）│
│                               │                                      │
│ 师Div RFA_TK_Nord  (57 营)     │ 条目 连Co 排Pl  装备      运输 经验 件数 槽位  pack# │  ← 右侧表格
│  └ 营Bn Descriptor_Deck_...    │ #1   Co0  Pl0  T72M1_TCH   —   继承  4   0-3   #2270│
│     └ 连Co 0 Howz_M101 ×6 …    │ #2   Co0  Pl0  BMP_2_SOV   —   3     3   4-6   #1183│
│        └ 排Pl 0 T72M1 ×4 …     │                                      │
│           └ #1 T72M1 ×4        │                                      │
├───────────────────────────────┴──────────────────────────────────────┤
│ 连Co 0 排Pl 0：2 条，占槽位 [0,1,2,3]  —— 改件数会重排该营全部下游窗口      │  ← 状态行
│ [改件数] [换装备] [插入条目] [删除条目] [批量替换] [保存]                  │  ← 动作按钮
│ ○ 未修改                                                              │  ← 改动标记
└──────────────────────────────────────────────────────────────────────┘
```

### 第一行：筛选（从左到右，一层比一层窄）

| 控件 | 作用 |
|---|---|
| `Mod` | 选要编辑的 mod。**所有其他内容都跟着它变**。 |
| `打开 mod 文件夹` | 手动指定 mod 位置。自动找不到时的兜底。 |
| `国家 Nat` | 按国家筛师。选了之后，右边的师列表里只剩这个国家的师。 |
| `师 Div` | 选师。**可以直接打字筛选**（框是空的，打第一个字就开始筛）。 |
| `营搜索` | 按营名筛树。 |
| 最右边的语言下拉 | 切界面语言。**切换不用重启，也不会丢未保存的改动。** |

#### 界面语言

下拉里每一项都用它自己的语言写自己的名字（`简体中文` / `English`），
所以你不需要先认出"语言"这两个字就能找到它。目前就这两种。

- **切换是即时的**：按钮、标签、提示、树里的文字一起变，正在编辑的文件不动。
- **选择会被记住**，下次启动还是它。
- **只列出已经翻好的语言**。某一语言还没翻完时它不会出现 —— 免得你点了之后
  看到的还是中文，像是坏了。
- 标准对话框（`QDialogButtonBox` 的确定/取消、文件选择框）由 Qt 自带翻译提供，
  不在本工具的词表里。

#### 深浅色

**界面跟随 Windows 的「应用模式」**（设置 → 个性化 → 颜色 → 选择默认应用模式）。
系统是深色，工具就是深色；**把系统切过去，工具会自己跟着变**，不用重启，
也不用重开 mod。

> 这条是特意做过的：工具打包用的 Qt 版本（6.3.2）里，Windows 原生样式
> **只认浅色** —— 系统明明是深色，窗口也还是白的。所以工具改成自己上色，
> 代价是不再是 Windows 原生外观，换来的是深浅两套配色在任何 Windows 上都一致。

> 忘了自己切到哪种语言、界面看不懂了？退出程序，用记事本打开
> `%LOCALAPPDATA%\WarnoNdfbinDecksEditor\settings.json`，把 `"language"` 改回
> `"zh_CN"` 即可。

几个容易困惑的地方：

- **选了国家之后，师下拉的第一项是「全部师（SOV · 54 师）」** —— 选它就能看这个国家全部 54 个师。
  但下拉会**自动停在第一个具体师上**，而不是停在"全部师"，因为"全部师"意味着 2208 个营，树太大了。
- **这些框看起来是空的，是故意的。** 当前选中的内容显示成灰色的"占位提示"，输入框本身留空 ——
  这样你打第一个字就是全新搜索，不会变成往原文字后面接字。
- **打完字按回车** 就跳到第一个匹配项。
- **打错了、不想要了，点别的地方（让它失去焦点）会自动撤销**，回到原来的选择；列表全空也不会把当前选择丢掉。
  注意：**只有正在打字时才会撤销**。一个字都没打就点走，选择原封不动。
- **改装备不会动你的筛选。** 换装备、改件数、插入/删除条目、批量替换，做完之后
  `国家 Nat`、`师 Div`、`营搜索` 都停在原处，左侧树不会跳到别的师去。

### 左侧：组织树

四层，从大到小：`师Div` → `营Bn` → `连Co` → `排Pl` → 具体条目。

- 括号里的数字是数量：师后面是营数，营后面是连数……
- 在营上点一下 → 右侧表格列出**整个营**的装备。
- 在连上点一下 → 表格里该连的行会**高亮**，方便看你这次改动会波及多少。
- 在排上点一下 → 表格自动**跳到该排第一行**，按钮立刻可用。

### 右侧：装备条目表

| 列 | 含义 |
|---|---|
| `条目` | 这是这个排里的第几条。`#1` 就是第一条。 |
| `连Co` / `排Pl` | 它属于哪个连、哪个排。 |
| `装备` | 单位名。 |
| `运输` | 运输载具。`—` 表示没有（徒步 / 自带）。 |
| `经验` | `1` / `2` / `3`，或者 `继承`（由所属师决定）。 |
| `件数` | 这一条有几件。 |
| `槽位` | 内部编号，**你不用管**。只是告诉你这一条占了几格。 |
| `pack#` | 内部编号，**你不用管**。 |

**一行是"一样装备"，不是"一辆车"。** 一条写着 `件数 4` 的装备在游戏里就是 4 辆，但它们在这张表里只占一行 —— 改的时候一起改，这也是为什么换装备不会出现"4 辆车里只有 1 辆变了"这种事。

### 底部：状态行 + 按钮

- 状态行：告诉你当前选中了什么、这次改动会影响多大范围。
- 按钮：见[第 4 章](#4-四个操作按需要看)。
- 最下面一行：`○ 未修改` / `● 已修改，未保存`。**看到实心圆点就说明还没存盘。**

## 4. 五个操作，按需要看

无论哪个操作，**第一步都是先在右侧表格里点一行**（或在左侧树里选中排）。

### 4.1 改件数

1. 点表格里的一行。
2. 按 `改件数`。
3. 弹窗显示"当前 4 队，占槽位 [0,1,2,3]"，输入新数字（1～99）。
4. 确定。

> 改一个排的件数，会**自动重排这个营里后面的所有格子**。这是正常的，也是必须的 —— 底层的格子是连成一片的，改了前面，后面就得跟着挪。工具会自己算好，你不用管。

### 4.2 换装备

1. 点表格里的一行（或者直接**双击**那一行）。
2. 弹出「换装备 · 新建装备组合」：

> 上面框里的"已有装备包 2690 个 / 可定义单位 2910 个"是打开某个真实 mod 时的实测值，换一个 mod 会变。
> 对话框顶部另外会显示 `牌组来源：C:\...\Deck.ndfbin` —— 那是你正在改的这一份文件的完整路径，
> 动手前扫一眼，确认改的是对的那一份。

```
┌ 换装备 · 新建装备组合 ──────────────────────────────────────┐
│ 已有装备包 2690 个（下面第 1 区）｜可定义单位 2910 个（第 2 区下拉）│
│                                                              │
│ 1  从本 mod 已有的装备包里选                                   │
│   搜索： [T72________________]   分组：[全部分组 ▾]            │
│   ┌────────────────────────────────────────────────────┐    │
│   │ T72_CMD_DDR                      #2260             │    │
│   │ T72M1_TCH          · 本mod        #2270             │    │
│   │ T72M1_CMD_DDR                    #2261             │    │
│   └────────────────────────────────────────────────────┘    │
│                                                              │
│ 或者 ↓ 在下面造一个本 mod 还没有的组合                          │
│   单位（可手输）      载具（可留空）      经验                  │
│   [T72M1_TCH    ▾]   [— 无 —      ▾]   [继承（不写 Xp）▾]     │
│   TDeckPackDescriptor                                         │
│     Unit = $/GFX/Unit/Descriptor_Unit_T72M1_TCH               │
│   ＋ 新组合 —— 保存时会新建一个 pack 对象                       │
└──────────────────────────────────────────────────────────────┘
```

3. **两种用法，二选一：**

   **用法 A：换成已有的装备**（最常用）
   在搜索框里打字，从列表里选一条。搜索支持：装备名、运输机名、pack 编号、
   甚至 `经验3` / `xp3` 这种写法。

   选中后，底部状态行会明确告诉你结果属于哪种情况：

   | 底部状态行 | 意思 |
   |---|---|
   | `✓ 将换成 pack#2270 —— T72M1_TCH` | 用列表里选中的那个（推荐） |
   | `✓ 本文件里已有这个组合 —— 将复用 pack#4686（不新建对象）` | 你手输的组合已存在，直接复用 |
   | `＋ 新组合 —— 保存时会新建一个 pack 对象` | 本 mod 范围内没有这个组合，会新造一个 |
   | `⚠ 这些名字在任何定义文件里都找不到：xxx` | 会再问你一次确不确定 |
   | `⚠ 这个组合本文件里只有 pack#N，而且只被 PvP/行动模式引用过` | 同上，会再问一次 |

   **用法 B：造一个本 mod 还没有的组合**
   比如"这台 T-72 装上那种运输车"或"同一装备换成经验 3 的版本"。
   动下半区的三个下拉框（单位 / 载具 / 经验），底部状态行会实时更新（见上表）。

4. 点确定。

**经验和运输怎么填？**

- `经验`：`继承（不写 Xp）` 是默认值，意思是"由所属师决定等级"，这也是游戏自己的常见写法。想强制指定就选 1 / 2 / 3。
- `载具`：留 `— 无 —` 就是不带运输。选了就是"坐这个载具"，最好不要尝试让不具备运载能力的单位充当载具，具体会怎样你可以试试。

> **点列表行 = 用现成的；动下半区 = 造新的。** 两个区不会互相干扰，底部状态行永远告诉你现在到底是哪种。

### 4.3 插入条目 / 删除条目

- `插入条目`：在那个排里**新增一样装备**。先弹出和上面一样的换装备对话框（选装备或造新组合），再问你件数。
- `删除条目`：把选中的那一条装备从排里删掉。

> 插入 / 删除的都是"排里面的装备条目"，不是营、连、排本身。想删整个排，得去改 mod 的编制文件（超出本工具范围）。

### 4.4 批量替换（一次改一大片）

这是最省力的功能：比如"把**整个苏联**的 Igla Manpad全换成箭-10"。

1. 在树里随便选一个位置作为**起点**（比如某个营）。
2. 按 `批量替换`。
3. 弹窗是一张**表格**，一行 = 一组配对：左边这件装备，换成它右边的目标。

```
┌ 批量替换装备 ──────────────────────────────────────────────────────────┐
│ 替换范围：[本排 Pl] [本连 Co] [本营 Bn] [本师 Div] [本国 Nat]            │
│ 当前：本国 Nat                                                         │
│ [搜索：输入字符缩小范围…]                                               │
│ ┌──┬───────────────────────────────┬─────────────────┬────────────┬───────┐
│ │☑ │ MANPAD_Igla_SOV [UAZ_469_SOV] │ 1780 条/2617 件 │ 箭-10_SOV  │ 改选… │
│ │  │ 经验1                          │                 │            │       │
│ ├──┼───────────────────────────────┼─────────────────┼────────────┼───────┤
│ │☑ │ T80BV_SOV 经验1                │  523 条/1512 件 │ T80U_SOV   │ 改选… │
│ ├──┼───────────────────────────────┼─────────────────┼────────────┼───────┤
│ │☐ │ MotRifles_SOV [BMP_1P_SOV]    │  486 条/1530 件 │（未选目标）│ 改选… │
│ └──┴───────────────────────────────┴─────────────────┴────────────┴───────┘
│ [本行改成…] [统一设为…] [清空目标]              [全选] [清空]            │
│ 400 种装备，已勾选 2 种                                                │
│ 影响范围：2 种装备 · 27 个营 · 96 个连 · …                              │
└────────────────────────────────────────────────────────────────────────┘
```

（列表每条会带上运输载具和 `经验N` 这类条件，用来区分**同一种装备的不同版本** ——
比如"坐吉普的 Igla"和"坐 BMP 的 Igla"就是两条。）

> 列表**按用量从多到少排序**，最多显示 400 种。范围开得越大，种类越多，
> 真正要替换的那件装备几乎总在最上面几行 —— 不用往下翻。
>
> **一行 = 一种装备，不是"一个装备包对象"。** 同一个 mod 里常常存在两个内容
> 完全一样、只是编号不同的装备包；工具会把它们并成一行显示，勾上这一行就把
> 两个都换掉。否则你会看到两行名字一模一样的条目，勾了一个却只换掉一半。

> #### 多对多：每行一个目标
>
> 每一行都有自己的目标，所以可以**各换各的** —— 比如"T-72M→T-80B、
> BMP-1→BMP-2"一次做完。三种填目标的方式：
>
> | 按钮 | 作用 |
> |---|---|
> | 行尾的 `改选…` | 只改**这一行**的目标（最直接） |
| `本行改成…` | 改**当前选中行**的目标（和行尾的 `改选…` 等价） |
> | `统一设为…` | 给**所有勾选行**设同一个目标（这就是原来"多对一"的做法） |
> | `清空目标` | 保留勾选，把目标全清掉重填 |
>
> 典型用法：勾上五行 → `统一设为…` 选一个 → 再单独改其中一行的目标做例外。
>
> - 勾选/取消直接点方框；`全选` / `清空` 一键处理整栏。
> - **勾选和目标都会跟着范围走**：从"本营"放大到"本师"，原来勾的仍然勾着、
>   配好的目标也还在 —— 你是把一次请求放大，而不是重填一遍。
> - **所有配对同时生效，不成链。** `A→B` 加 `B→A` 就是**互换**，
>   不会先变 B 再变回去。这也意味着 `A→B`、`B→C` 的结果是 A 变 B、B 变 C，
>   而不是 A 变 C。
> - **同时生效也意味着一次重排**：底层是"每个受影响的营重排一遍"，不是"每组
>   配对各来一遍"，所以配 5 组和 1 组开销一样。

> #### 搜索框：先筛再勾
>
> 左栏上方有个搜索框，边打字符边筛。匹配的是**整行文字** —— 装备名、
> 运输载具、`经验N` 都能搜（`T80`、`Igla`、`经验2` 都行）。
>
> - **筛选只决定看得见什么，绝不动你勾过的。** 勾了 5 种，再打字让其中 3 种
>   隐藏起来，那 3 种**仍然是勾着的**，计数照样算它 —— 底部会直接写明真实
>   数量（`筛选出 12 / 400 种，已勾选 5 种`）。这是刻意的：如果打字顺手取消
>   了勾选，你一边缩小范围一边就在悄悄缩小这次替换，而屏幕上没有任何提示。
> - `全选` 只勾**当前看得见的**（刚筛完就点它 = "筛出来的这些我全要"）；
>   `清空` 则连隐藏的一起清掉，所以永远有一条回到干净状态的路。
> - 换范围（比如从本营放大到本师）时**搜索词会留着**，不用重打。
> - 右边的「选择装备…」开在当前选中的那一行上；那一行要是被筛掉了，
>   会自动落到一个看得见的行上。

4. **选范围**（五个按钮，越往右越大）：

   | 按钮 | 范围 | 实测例子 |
   |---|---|---|
   | `本排 Pl` | 只有你选中的这一排 | 1 种装备 |
   | `本连 Co` | 整个连 | |
   | `本营 Bn` | 整个营 | |
   | `本师 Div` | 整个师 | 61 种装备 |
   | `本国 Nat` | **整个国家**（这个师的所属国），比如整个苏联 | 400+ 种（触顶） |

   切换范围时，左栏列表会实时刷新，数字也会变 —— 那就是"爆炸半径"。

5. **勾选**要替换掉的装备（可多选），再逐行用「本行改成…」或批量用
   「统一设为…」选**换成什么**。

   两边都选好后，底部会显示这次会改多少东西。这是**真实输出**（在某个 mod 里把
   苏联全国的 `MANPAD_Igla_SOV [UAZ_469_SOV] 经验1` 换掉）：

   ```
   影响范围：355 个营 · 858 个连 · 1780 个排 · 1780 条装备 · 2617 件单位
   件数与槽位顺序保持不变；共改写 355 个营。
   ```

   多来源时影响范围前面会多一项"N 种装备"，例如
   `影响范围：2 种装备 · 27 个营 · 96 个连 · 96 个排 · 96 条装备 · 192 件单位`。

   **「件数」和「槽位顺序」不会变** —— 批量替换只换装备种类，不动数量、不动排布。

   **要么全部成立，要么一条都不改。** 只要有一行不成立，`替换` 按钮就是灰的，
   底部会指名第几行、为什么：

   | 情况 | 提示 |
   |---|---|
   | 某行勾选了但没填目标 | `第 3 行还没有选目标 —— 整体不会执行。` |
   | 某行的目标和它自己相同 | `第 5 行的目标与来源相同 —— 整体不会执行。` |
   | 勾选的来源在范围内已经不存在了 | 引擎侧拒绝，什么都不写 |

   换成同一件装备是没意义的，所以工具不猜你的意图 —— 它直接拒绝并告诉你是哪一行。

6. 确认。完成后弹窗会告诉你影响了多少条、多少件、多少个营。

> 范围按钮里 `本国 Nat` 只有在当前营属于某个可识别的国家时才可点。
> 如果那个营没有国家标记（显示为"未标师的营"），这个按钮会是灰的，鼠标停上去会说明原因。
>
> **换国家范围不会误伤别国**：实测用一个被多个国家共用的装备验证过 ——
> 同一件装备同时被东德和苏联的营使用，在"苏联全国"范围内替换后，
> 苏联的引用**全部清空**，东德的那 12 处**一处未动**。

### 4.5 导出装备清单（查这个 mod 到底有什么）

编辑时最有用的一个问题不是「这一条怎么改」，而是**「我这个 mod 里到底有什么、哪些
新装备还进不了将军模式」**。树和表一次只显示一个营，翻不出这个答案 —— 所以动作栏里
有一个 `导出装备清单`。

点它 → 选一个保存位置 → 得到**一张单文件 HTML**（断网也能开，能搜能筛能排序）：

| 表 | 回答什么 |
|---|---|
| **概览** | 装备总数、★ 新增几个、几个已经有 pack、几个"完全无 pack" |
| **各国矩阵** | 每个国家「有 pack / 仅作载具 / 无 pack / ★ 新增」各多少 —— 一眼看出哪个国家还没进 AG |
| **装备速查** | 每件装备的角色、战略分类、国家、价格，以及它有 0/1/N 个 pack |
| **Pack 速查** | 每个 pack 是什么内容、被几个牌组引用、是不是孤儿 |
| **需生成 Pack 的装备** | **"为什么装备选择器里选不到"就是这一批** |

> **"完全无 pack" 是什么意思**：装备在游戏里存在，但没有任何 AG pack 指向它，
> 所以在将军模式的装备选择器里找不到。要用它，得先给它建一个 pack
> （就是「插入条目」时提示你去建的那个东西）。
>
> **"孤儿 pack" 不是错误**：定义了但没有任何牌组用它 —— 对改编制的人来说
> 反而是现成的素材。

两个必知的前提：

- **它只读**，不碰 mod 里任何文件；当前没保存的改动也不会被它写出去。
- **它读的是编译产物**（`Gen/NDF/GFX/Unit.ndfbin` + `Deck.ndfbin`），所以能看到
  你新加的单位和 pack。**没有 `Unit.ndfbin` 的 mod 导不出来** —— 那说明这个 mod
  根本没改装备（只改牌组的 mod 就是这样），弹窗会直说。只带 `Unit` 不带 `Deck`
  的 mod 仍然能导，但 pack 与牌组那一半会标明"来自原版模板"。

导出之后弹窗会交底：读了哪几个文件、多少条引用没连上、多少对象没计入 —— 点
`详细信息` 能看到全部。**不要忽略那里的提醒**：表里最容易出的问题是"读错了文件"
和"几条引用对不上"，它们都不会让页面崩，只会让数字悄悄不对。

## 5. 保存：先看这一节再动手

### 保存流程

点 `保存` 之后会发生四件事：

1. **自检**。工具会检查整份文件有没有结构错误。
   - 没问题 → 继续。
   - 有硬错误 → **拒绝保存**。弹窗会告诉你**是哪几个营**、**在这个营的哪个连/排**，
     最后给出「共几条、涉及几个营」。文件一个字节都不会动。
2. **选路径**。弹"保存到"对话框，**默认就是你现在打开的那个文件**。
   - 直接点保存 = 覆盖原文件（推荐，也是常规做法）。
   - 也可以另存到别处（原文件不会被碰，也就不会生成 `.bak`）。
3. **自动备份**。覆盖原文件时，先写一份 `Deck.ndfbin.bak` 放在同一个文件夹。
4. **写入**，弹窗显示"已保存 + 路径 + 字节数"。

### 拒绝保存时那两条，怎么读

自检报的错里，你大概率只会遇到下面两条。它们都是**别人给你的文件**上才有的毛病，
编辑器自己改不出这种状态（它每次改动都会把那个营的槽池重排成唯一合法布局）。

**① 槽池里有个洞**（最常见）

```
1 slot(s) 3..3 belong to no platoon; every window after them is shifted 1 slot(s) late
    ([4..9]x6 starts at 4)
    — pion_SOV_1GTA_595Reco · 连0/排1
```

读法：槽池里第 `3` 号槽**没有任何排引用它**（`3..3` 就是这一格）。
因为窗口是顺着排的，**它后面每一个窗口都被顶晚了一格** —— 那条本来该从第 3 格
开始的窗口，现在从第 4 格开始（`[4..9]x6 starts at 4`）。弹窗指的位置
（`连0/排1`）就是**第一个被顶晚的排**，从那儿看起。

**② 窗口真的伸到槽池外面去了**

```
window [97..102]x6 exceeds the 100-slot pool (it reaches slot 102)
    — pion_XXX · 连5/排1
```

读法：这条排要 6 个槽（97 到 102），但整份文件的槽池只有 100 格。
**最后那几格根本不存在** —— 游戏不会报错，它会按
`min(件数, 池长 − 起点)` **静默少给兵**（这里只会派 3 个）。所以编辑器宁可拦住不让你保存。

> 这条通常**连着**一条 `Σ(Number)=… but the windows only resolve … slot(s)` 一起出现，
> 说的是同一件事（声明的件数比池子里真实存在的槽多）。看窗口那条就够了。

**两条的清法一样**：对**弹窗点名的那个营**做**任意一次**改动 —— 最省事是选中一条
「改件数」，把数字**填回原来的值**。编辑器会按唯一合法的布局把这一个营的槽池整个重排，
错误随之消失；改完再保存就正常了。

> 常见来源是 mod 生成工具（编译时漏掉一个槽却没重编号）、手工改过的文件、
> 或其它工具写出来的文件。**不是你的操作造成的** —— 看到它别慌，按上面清掉即可。

### 关于备份

```
你的mod\Gen\NDF\GFX\
    Deck.ndfbin          ← 游戏读这个
    Deck.ndfbin.bak      ← 工具自动存的上一版
```

**想恢复原状**：把 `Deck.ndfbin.bak` 改名成 `Deck.ndfbin`（覆盖掉现在这个）。就这么简单。

但注意：**每次保存都会覆盖 `.bak`**。所以如果你连着改了三次，`.bak` 里是第二次的结果，不是最初的样子。所以[第 2 章第 0 步](#第-0-步先备份30-秒别跳过)那份手动备份别省。

### 两个必须知道的前提

**一、编辑器改的是"部署目录"里那一份。**

如果你是从 mod 的**工程源**（通常在 `WARNO\Mods\你的mod\`）构建出来的 mod，那么游戏实际读取的是"保存的游戏"里的那份部署文件，编辑器改的也是它。

**之后如果你重新构建 / 重新导出这个 mod，改动可能被覆盖掉。** 本工具不会把改动同步回工程源 —— 那一步得你自己来。

**二、改创意工坊的 mod 要小心。**

Steam 创意工坊的 mod 保存在 Steam 目录里。你可以改，但 **mod 作者一更新，Steam 一同步，你的改动就没了**。

所以更稳妥的做法是：把工坊 mod 复制一份出来，放到"保存的游戏\EugenSystems\WARNO\mod\你的新名字\"，然后改用那一份。

## 6. 为什么找不到我的装备 / 我的 Mod

这一节解释本工具最重要的一条设计原则，看完就明白为什么"有些东西不在列表里"。

### 6.1 装备列表里的装备是从哪来的

「换装备」里那个"单位"下拉框，内容由三个来源合成：

| 来源 | 说明 |
|---|---|
| **原版数据** | 游戏自带的所有单位（实测 2898 个），比如 `Su_27K_SOV`。 |
| **本 mod 定义的单位** | 这个 mod 自己新增的（比如创意工坊 mod 里的新飞机）。 |
| **本文件引用过的** | 你现在打开的这份牌组文件里已经用到的 |

下拉框里后面标了 `· 原版` 或 `· 本mod` 的，就是对应来源。**什么都没标**的，说明这个 mod 的将军模式牌组已经在用了。

所以：**原版单位和本 mod 的新单位都能选到。** 如果某个名字明明该有却搜不到，多半是它既不在原版、也不在这个 mod 的定义文件里（比如拼错了）。

> 实测参考（打开某个真实 mod 时）：下拉里有 2910 个单位可挑 = 原版 2898 + 该文件已引用过的 2389（两者有重叠，所以不是简单相加）。

### 6.2 但是：绝对不会跨 Mod 借装备

上一条"已有装备包"列表（第 1 区）里，**只有你这个 mod 已经引用过的装备**。

为什么这么严格？因为如果你从**别的 mod** 里引一个单位过来，而这个单位在**当前 mod** 里根本不存在 —— 游戏找不到它，**不会报错，只会静默变成一个空装备**。你进了游戏才发现东西不见了，还查不出原因。

所以工具把这条做成硬性限制：**只能在本 mod 的范围内选**。手动输入装备名也一样，不在本 mod 定义范围里的会被明确拒绝：

```
✓ 使用 pack#2270                       ← 本 mod 有，接受
✗ 本 mod 里没有 Descriptor_Unit_BMP_3_SOV —— 不会引入其它 mod 的装备
```

### 6.3 找不到我的 Mod

按顺序试：

**第一步：看清楚下拉列表。**
- 灰着的（`无牌组`）说明这个 mod 没有编译好的 `Deck.ndfbin`。你需要在 mod 的工程里先构建一次。
- 不在列表里 → 往下走。

**第二步：点「打开 mod 文件夹」，手动指定。**
这个按钮能吃下四种东西，选哪一级都行：

1. **单个 mod 文件夹** —— 里面直接有 `Gen\` 或 `Config.ini`
2. **装着多个 mod 的父目录** —— 比如"保存的游戏\...\WARNO\mod"
3. **Steam 的库目录** —— 比如 `D:\Steam\steamapps`
4. **整个解压出来的文件夹** —— 比如从网上下载的一个 mod 压缩包解开之后

选完之后：
- 找到的 mod 会被**加进下拉列表**（标 `· 手动`），并且自动打开第一个能用的。
- 如果一个都没找到，弹窗会告诉你："里面没有 mod：既不是含 Gen/ 或 Config.ini 的 mod 目录，子目录里也没有这样的 mod。"

**第三步：确认路径对不对。**
mod 的判据是这一层：`Gen\NDF\GFX\Deck.ndfbin` 存在（或者至少有 `Gen\` 或 `Config.ini`）。如果那个文件夹里只有一堆 `.ndf` 文本文件，说明你指到**工程源**去了 —— 工程源要先构建成部署目录才能编辑。

### 6.4 为什么有些装备在游戏里能看到，这里却没有

因为游戏显示的是**本地化名称**（`T-72M1`），而编辑器里的搜索是**内部名**（`T72M1_TCH`）。

两个办法：
1. 在「换装备」的搜索框里试着搜内部名的关键字，比如搜 `T72` 会列出所有 T-72 系。
2. 认不出某个内部名的装备时，看它在表格里**上下文**：它在哪个营、哪个排、跟什么装备在一起，一般就能判断。

另外，如果某个 mod 没带本地化字典（很常见），表格里的连名、排名会显示成"未知" —— 那不是错误，只说明这个 mod 没提供这些名字。此时编辑器会**改用"这一排装了什么"来给排命名**，比如 `排Pl 0 T72M1 ×4 · BMP-2 ×2`，比一个名字还清楚。

## 7. 名词对照表

| 界面上的词 | 你可以理解成 |
|---|---|
| `Mod` | 模组。你要编辑的对象。 |
| `国家 Nat` | 按国家过滤（SOV 苏联 / RFA 西德 / RDA 东德 / US 美国 …） |
| `师 Div` | 师 / 师级单位 |
| `营Bn` | 营。将军模式里在地图上移动的那个"棋子"通常就是营。 |
| `连Co` | 连。一个营下面的分组。 |
| `排Pl` | 排。一个连下面的分组。**装备就是挂在这一层上的。** |
| `条目` | 排里面的一条装备记录。**这是你能改的最小单位。** |
| `件数` | 这一条装备有几件。 |
| `槽位` | 内部编号，忽略它。 |
| `pack#` | 内部编号，忽略它。 |
| `经验` | 单位等级。`继承` = 由所属师决定。 |
| `运输` | 运输载具。`—` = 没有。 |
| `换装备` | 把这一条装备换成别的。也可以造新组合。 |
| `批量替换` | 一个范围内所有同类装备一起换。 |

**国家代码**（师名前缀，也是「国家 Nat」下拉里的）：

```
SOV 苏联    RFA 西德    RDA 东德     US 美国      FR 法国     UK 英国
POL 波兰    TCH 捷克斯洛伐克   NL 荷兰   BEL 比利时   CAN 加拿大   ESP 西班牙
NATO 北约
```

上面是某个真实 mod 里实际出现的 13 个国家（大小依次为 SOV 54 师 / 515 营、
RFA 31 师 / 396 营、US 39 师 / 265 营、POL 25 师 / 233 营、RDA 18 师 / 229 营 ……）。
别的 mod 可能多几个或少几个 —— 下拉列表里有什么就是什么。

> 注意：东德在**师的名字**里写 `RDA`，在**单位的名字**里写 `DDR`。这是游戏自己的历史遗留（开发商是法国公司，用了法语缩写）。
> 编辑器里两个都能搜到 —— 在「国家 Nat」里输入 `DDR` 或 `东德` 都会命中 `RDA`。

## 8. 常见问题与故障处理

### 1. 双击 EXE 没反应

- **等 5～10 秒**。第一次运行要解压，而且杀毒软件会扫描这个新文件。
- 还是没反应：打开任务管理器（`Ctrl+Shift+Esc`）看看有没有同名进程在跑。
- 被拦截的可能性最大 —— 检查杀毒软件/Windows 安全中心的"保护历史记录"，看看是不是被隔离了。

### 2. 弹"Windows 已保护你的电脑"

正常现象，因为程序**没有数字签名**。点 `更多信息` → `仍要运行`。

### 3. 列表里的 mod 是灰的（显示"无牌组"）

这个 mod 里没有 `Gen\NDF\GFX\Deck.ndfbin`。你需要在它的工程里先构建一次，或者确认下载的是完整版本。

### 4. 找不到某个装备

**先想一下：这个 mod 里有它吗？** 本工具不跨 Mod 借装备（[原因](#62-但是绝对不会跨-mod-借装备)）。

如果你是从**别的 mod** 里看到这个装备的，那它不在当前 mod 里，选不了 —— 这是对的，强行选会让游戏里出现空装备。

### 5. 保存了，但游戏里没变化

按顺序检查：

1. **游戏完全退出了吗**？退到主菜单可能不够，要整个退出再启动。
2. **你改的是游戏读的那份文件吗**？在「换装备」对话框顶部能看到这一行：
   `牌组来源：C:\...\ Deck.ndfbin` —— 这个路径要和游戏实际加载的那份一致。
   （保存对话框里也会显示完整路径。）
3. **看文件时间戳**。在文件资源管理器里打开那个 `Deck.ndfbin` 所在的文件夹，确认修改时间就是刚才。
4. **是不是没有重新开始战役**？正在进行的战役可能已经加载过牌组数据了。
5. 确认你改的那个营，在游戏里看的是同一个营。

### 6. 弹"有硬错误，不能保存"

工具发现这份文件的结构有问题，拒绝写入（这是好事 —— 避免把坏数据存回去）。

常见原因和"混合窗口"有关：一条装备记录声明"这里有 3 件"，但它实际占的 3 个格子里放了**两种不同的装备**。

**怎么办**：
- 如果你**从没改过**这个文件就报错 → 这份文件本来就是坏的（可能来自另一个工具或旧版本）。用 `Deck.ndfbin.bak` 或你自己的备份恢复。
- 如果**改完之后**才报错 → 关掉窗口不要保存，用 `.bak` 恢复，然后重新做一遍这次改动。

### 7. 改坏了，怎么恢复

```
把 Deck.ndfbin.bak  改名成  Deck.ndfbin
```

（先把现在这个坏的重命名成别的，比如 `Deck.ndfbin.坏的`，再改名 —— 这样万一后悔还有退路。）

如果你有手动备份（[第 2 章第 0 步](#第-0-步先备份30-秒别跳过)那份），更保险。

### 8. 程序启动就崩 / 闪一下就没了

打开这个文件夹找日志：

```
%LOCALAPPDATA%\WarnoNdfbinDecksEditor\
```

- `app.log` —— 每次启动都会写。能看到它启动到哪一步。
- `crash.log` —— 崩了才有。里面有完整的错误信息。

（在文件资源管理器地址栏直接粘贴上面那行就能跳过去。）

如果是启动就弹窗报错，那个弹窗会直接告诉你 `crash.log` 的位置。

### 9. 能把配置文件放到别的地方吗

设置环境变量 `NDFDECKS_HOME` 指向任意目录，日志就会写到那里。一般用不上。

### 10. 换装备时底部出现黄色警告

两种，都是**确认框**，不是错误：

```
⚠ 这些名字在任何定义文件里都找不到：xxx
   已查过：本 mod 的 Unit.ndfbin、原版数据（base.zip）、以及本文件引用过的全部单位。
```

意思是这个名字在任何地方都没找到。

**如果确实是你 mod 里刚加的单位**，而工具读不到（比如你只改了工程源、还没构建），可以继续 —— 但请**进游戏确认它真的存在**，否则会变成空装备。

**如果只是打错了字**，点"否"，回去改。

另一种：

```
⚠ 这个组合本文件里只有 pack#N，而且只被 PvP/行动模式引用过 —— 将军模式从未用过它。
```

意思是这个组合存在，但它只被 PvP / 行动模式的牌组用过。将军模式用它是**没问题的**（结构一样），只是这个 mod 从来没这么配过。确认即可。

## 9. 名词释义（想搞明白原理再看）

不感兴趣可以跳过，不影响使用。

### `Deck.ndfbin` 是什么

WARNO 把游戏数据编译成 `.ndfbin` 二进制文件。`Deck.ndfbin` 就是"牌组"文件，里面记录着每个营由哪些单位组成。

它是**编译产物** —— 人不能直接读，所以以前想改一点东西就得去改源码然后重新编译整个 mod。本工具直接读写这个二进制文件，让你跳过那一步。

### "条目"和"槽位"到底什么关系

这是本工具里唯一一个稍微绕的概念，但理解了就不会误操作。

`Deck.ndfbin` 内部不是"一个装备一个格子"，而是：

```
连Co0 / 排Pl0 / 第1条  声明：3 件   →  占用 槽位 0、1、2
连Co0 / 排Pl0 / 第2条  声明：2 件   →  占用 槽位 3、4
连Co0 / 排Pl1 / 第1条  声明：1 件   →  占用 槽位 5
```

也就是说，**一个"条目"占着连续的好几个"槽位"，而且这些槽位里必须放同一种装备**（这是游戏引擎的硬性要求）。

这带来两个后果，也是本工具几个设计决定的原因：

1. **你改的是"条目"，不是"槽位"。** 早先的版本允许一格一格改，结果出现了"3 件装备里只有 1 件被换掉、另外 2 件还是旧的"这种状态 —— 文件结构坏了，游戏里会出错。现在整个条目一起改，**结构上不可能出现半改状态**。
2. **改一个排的件数会重排后面所有条目。** 因为格子是连成一片的，前面多占一格，后面所有条目的起始位置都要往后挪。工具会自动完成这件事。这也解释了状态行那句"改件数会重排该营全部下游窗口"。

### 为什么不能跨 Mod

游戏加载 mod 时，只加载这个 mod 定义的内容。如果 A mod 的牌组里写了"用 B mod 的某单位"，而 B 没装（或者装的版本里没这个单位），游戏找不到定义 —— **它不会报错退出，而是当作空装备处理**。

这种错误极难排查：游戏能开、能进战役、就是某个单位不见了。所以本工具宁可限制得死一点。

### 为什么 PvP 专用的装备不列出来

同一个 `Deck.ndfbin` 里同时装着**将军模式**和 **PvP / 行动模式**两套牌组数据。

实测数据：将军模式引用 2690 个装备包，PvP 引用 2483 个，**两边几乎零重叠**。它们是两套不兼容的结构。

如果把 PvP 的包混进将军模式的牌组，游戏会出错。所以列表里只出现**被将军模式牌组引用过**的那些。

有一个反直觉的细节：过去一度用"有没有经验等级定义"来区分，结果**误杀了 311 个将军模式合法使用的装备**（不写经验是合法的，意思是"继承师的经验"）。所以判据最后换成了"是否被将军模式牌组引用过" —— 这才是真实的依据。

### 为什么启动要等一两秒

程序是个**单文件 EXE**（约 37 MB，PySide6 界面框架本身就不小）。单文件的意思是：整个程序被压缩在一个文件里，每次启动时先解压到临时目录再运行。

- **热启动**（开机后跑过至少一次）：约 1.3 秒
- **冷启动**（刚开机、或刚拷过来第一次运行）：5 秒左右 —— 杀毒软件要完整扫描这个新文件

好处是复制一个文件就能给别人用，不用装、不用配。这个取舍是故意的。

（包里确实有一大块用不到的东西 —— 编译框架自带的 20 MB 显卡兼容库、6 MB 的界面翻译文件 —— 都可以去掉，去掉后文件能小一半左右。但那需要改构建方式，留作后续版本。）
